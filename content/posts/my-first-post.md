# 我的第一篇博客

今天，我第一次搭建了自己的个人博客。

这也是我第一次真正拥有一个属于自己的互联网空间。

目前使用的技术：

- Git
- Hugo
- PaperMod
- VS Code

## 为什么开始写博客？

以前学到东西以后，很多内容很快就忘记了。

聊天记录会消失，网页收藏越来越多，电脑里的文件也越来越乱。

所以我想建立一个属于自己的地方，把真正让我思考过的东西记录下来。

这里以后会记录：

- 信息安全
- Python
- 数据结构
- AI
- 有趣的技术
- 对世界的一些思考

## 一个新的开始

现在这个博客还很简单。

但我希望几年以后再回来看，会发现这里已经留下了很多东西。

也许到那个时候，我可以看到自己是怎么一步一步走过来的。

博客的第一步，完成。🌱
